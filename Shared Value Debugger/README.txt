Displays shared variables live on-screen to help you debug projects.


In Shared Keys, type your variables, separated by commas:

    'value1, value2, #n, value3'

    #n adds a visual gap.

    Arrays (e.g. value = [a, b, c]) are expandable.


Click the debug window layer to toggle visibility.
Click array entries to expand/collapse them.


Only enter keys (e.g., 'value', not 'shared.value').
Uses fallback caching if shared value disappears (null / undefined).
